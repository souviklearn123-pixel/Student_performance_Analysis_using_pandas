---------Student Performance Analysis & Data Visualization-----------

This repository contains Python projects for analyzing and visualizing student performance data using Pandas, Matplotlib, and Seaborn.

----------Projects------------

1. Student Performance Analysis using Pandas
- Data cleaning and preprocessing
- Handling missing values
- Data filtering and sorting
- Grouping and aggregation
- Statistical analysis of student marks
- Analysis based on city, gender, subject, and attendance

2. Student Performance Data Visualization
- Bar charts
- Histograms
- Box plots
- Scatter plots
- Count plots
- Correlation heatmap
- Trend line visualization
- Visual analysis of Age, Marks, and Attendance

3. Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

4.Dataset

The dataset contains student information such as:
- Student ID
- Name
- City
- Gender
- Age
- Subject
- Marks
- Attendance

------- Purpose-------

The purpose of these projects is to understand student performance data through data analysis and visualization techniques.
